# Find the moment

1. Get four facts: bridge id, what happened, the camera, and a time range. If they name an hour but not the minutes, use that whole hour. If they name no range, ask once and stop until they answer.
2. Follow `skills/rikuy-video/SKILL.md`, historical clip, for that bridge, camera, and range.
3. Done when every returned clip URL is in your reply, each with its `name`. When one clip's name contains the moment they named, put that URL first and say it is the one that covers the moment.
