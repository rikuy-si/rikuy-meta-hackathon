# Language Rule

All authored repository, issue, and project content must be in English, regardless of the user's language; original sources and direct quotations may retain their original language.

# Agent Runtime

Skills in `skills/` run in the Muse Code agent on pi.dev (model: Muse Wonder). The same agent writes or adapts pipeline code and does every look-and-analyze step a skill names.
